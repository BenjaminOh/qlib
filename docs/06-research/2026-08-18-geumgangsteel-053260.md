## 해석 (원문 문법 대조)

1. **"구리 값 최고가 경신" — 원자재 앵커, 표본 최초.** 11개 표본 전체에 구리·원자재·LME
   언급이 **0건**이었다. 사실 여부도 검증됨: LME 구리가 8/6 **US$14,455/t 사상 최고**를
   찍었고 8/17 블룸버그가 재차 "record high" 보도 — 추천 전일이다.
   **다만 금강철강은 철강재 유통사로 구리 직접 노출이 아니다.** 즉 이 앵커는 개별 종목의
   원가·매출 연결이 아니라 **원자재 전반 강세 → 금속 유통주 동반**이라는 섹터 심리 연동이다.
   11호의 "보호예수 해제일 캘린더"에 이어 **우리 시스템에 없는 외부 데이터 소스 2번째**.
2. **"오늘 눌림 차트 맥점"**: 8/11 종가 고점 6,230 대비 오늘 종가 **−8.4%**. 눌림 3일차인데
   8/13→8/14→8/18 종가가 5,700 / 5,710 / 5,710 으로 **거의 완전 횡보** — 매물 소화 자리.
   거래량도 511만 → 27만 → 34만으로 말랐다.
3. **"반등 최고자리"**: 오늘 저가 5,340까지 밀렸다가 종가 5,710 회복 = **아랫꼬리 양봉**
   (시 5,670 < 종 5,710). 지엔씨에너지 8호의 "긴 아랫꼬리 양봉 = 눌림 흡수"와 같은 문법.
4. **손절 5,000 = 오늘 저가 −6.4% + 라운드 넘버**. 앵커 사전 대조:
   - 오늘 저가 5,340 × 0.94 ≈ 5,020 → **"눌림 저가 버퍼"** 계열 (씨피시스템·이랜시스 −4%보다
     조금 넓은 −6%대)
   - 8/7 돌파 캔들 몸통(시 4,850 ~ 종 5,320) 하단 방어 — "돌파 기점 붕괴 시 무효"와도 정합
   - 라운드 넘버 선호는 솔트룩스 7호에서 이미 제기된 가능성
   세 해석이 5,000 부근에 수렴하므로 **구조 레벨 앵커로 판정**. 사전 미등재 변형 아님.

## 우리 시스템 대조

- **15:05 스크리너 미포착 — H-풀편향 5건째.** 오늘 등락률이 **정확히 0.00%**(5,710 = 8/14
  종가)라 KIS 등락률 상위 풀에 진입 자체가 불가능하다. 11호 시점 4건 → 5건. 눌림·횡보일
  추천은 현행 풀 방식으로 구조적으로 못 잡는다는 결론이 굳어졌다.
- **★ 다만 풀에만 있었으면 C패턴이 잡았을 자리다.** 요건 대조:

  | C 조건 | 실측 | 판정 |
  |---|---|---|
  | 10일 내 ≥+25% 급등 | 4,610 → 6,230 = **+35%** | ✅ |
  | 고점 대비 −8~−25% | **−8.4%** | ✅ (경계 통과) |
  | 당일 양봉 | 종 5,710 > 시 5,670 | ✅ |

- **손절 대조 — 우리가 오히려 더 타이트하다.**

  | | 손절 | 리스크 |
  |---|---|---|
  | 우리 C패턴 `min(최근5봉 저가) × 0.96` = 5,340 × 0.96 | **5,126** | −10.2% |
  | 추천자 | 5,000 | −12.4% |
  | (참고) 캡 −15% 바닥 | 4,854 | — |

  **캡이 바인딩하지 않는다** (5,126 > 4,854). C패턴은 구조 손절이 그대로 살아남고,
  추천자보다 2.5% 타이트한 값이 나온다. **A패턴만 캡에 뭉개진다는 진단의 반대편 증거.**

- **같은 날 13호 지투파워와 테마 연결**: 지투파워는 수배전반·ESS로 **구리가 핵심 투입재**
  이고 전력망 투자 직접 수혜다. LME 구리 최고가의 동인이 "AI 데이터센터 + 전력망"인 것을
  감안하면, 오늘 두 추천이 **하나의 테마 묶음**일 가능성이 있다. 상세는 13호 문서 참조.
