## 우리 시스템 대조

### ★★ `len(bars) < 21` — 구조적 배제

`app/api/services/market_screener.py:52`
```python
def _classify(bars: list[dict]) -> dict | None:
    if len(bars) < 21:
        return None
```

**봉이 21개 미만이면 패턴 판정 자체를 하지 않는다.** 오늘 기준 이 종목의 봉은 **6개**다
(08-18·19·20·21·22·25). 어떤 값이 들어와도 `None` 이 반환된다.

파생 지표도 전부 계산 불가다:

| 지표 | 코드 | 필요 봉 |
|---|---|---|
| `ret20` | `today["close"] / closes[-21] - 1` | 21 |
| A패턴 30일 신고가 | `max(closes[:-1])` | 30 |
| `vol20` 거래량 배수 | `sum(vols[-21:-1]) / 20` | 21 |
| C패턴 `base` | `min(closes[-20:-8])` | 20 |
| D패턴 `ma20` | `sum(closes[-20:]) / 20` | 20 |

→ **신규 상장주는 최소 21거래일(약 한 달)이 지나야 후보가 될 수 있다.**
