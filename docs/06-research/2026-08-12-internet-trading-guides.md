# 인터넷 매매 가이드 수집 — 기존 시스템 대비표

> 발상(사용자 2026-08-12): "인터넷의 주식 고수 가이드(이건 해라/하지 마라)를 모아 정리한 후
> 모의투자 로직에 추가하면 어떤가? 이미 되어 있나?" — 수집·정리해 보니 상당수가 이미
> 자체 실측·역설계 경로로 구현돼 있었다. 이 문서는 그 대응 관계를 표로 고정한다.
> **문서 전용 — 전략 동결 원칙에 따라 코드 반영은 테스트 종료 후 판단. 이 문서 자체는
> 어떤 규칙 변경의 근거도 아니다.**

## 미반영(🕐) 후보 요약 — 테스트 종료 후 검토 순서 제안

1. **리스크 기반 포지션 사이징** (#24) — 구조적 손절폭 역산 수량. 기존 슬롯 구조에 곱셈 하나로 얹을 수 있어 비용 대비 효과 큼
2. **시장 국면 필터** (#27) — market_flow 오버레이를 게이트로 승격하는 실험
3. **추세 게이트 전면화** (#5) — surge의 MA20 조건을 타 전략에도 적용할지
4. **분할매수 다단화 / 피라미딩** (#12, #13) — 진입 구조 변경이라 가장 큰 수술, 후순위
5. **손절 후 재진입 쿨다운** (#30), **펀더멘털 필터** (#6) — 표본상 문제가 관측되면 그때

🔬 항목(#9, #10, #11, #14, #21)은 이미 자체 파이프라인이 처리 중이므로 **별도 조치 불요** —
`retrospective.py` 의 `scoreboard()`가 임계치 도달 시 필터 시뮬 검증을 제안한다.

## 반영 절차 (재확인)

1. **전략 동결**: 테스트 종료까지 이 문서의 어떤 항목도 코드·설정에 반영하지 않는다. 버그 수정만 승인 후 진행.
2. 테스트 종료 후 반영하고 싶은 항목이 생기면: **가설(H-) 등록 → 실측 표본 축적 → 임계치 도달 시 필터 시뮬 검증 → 승격**. 인터넷 가이드라는 이유로 이 경로를 건너뛰지 않는다 — 표본 10호가 보여줬듯 이 시스템의 규칙은 실측이 원천이다.
3. 이 문서는 "무엇이 이미 있고 무엇이 없는지"의 지도이며, 우선순위 재론의 출발점으로만 쓴다.
